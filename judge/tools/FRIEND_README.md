# 이코테 Judge

「이것이 취업을 위한 코딩 테스트다 with 파이썬」(나동빈, 한빛미디어)에 나오는 71문제를 내 컴퓨터에서 채점해 보는 사이트입니다.

> 문제 설명과 그림은 책 내용이니, 개인 공부용으로만 쓰고 인터넷에 공개하지 마세요.

## 준비
- **Python 3.11 이상**: https://www.python.org/downloads/ 에서 설치하세요.
  - Mac 기본 python3(3.9)로도 돌아가지만, 프로그래머스형 문제는 시간 측정이 느리게 나올 수 있습니다.
  - Windows는 설치 화면에서 **"Add python.exe to PATH"**를 꼭 체크하세요.
- 인터넷: 처음 실행할 때 채점용 PyPy(약 30MB)를 자동으로 내려받습니다.

## 실행
- **Mac**: `이코테 Judge 실행 (Mac).command`를 더블클릭하세요.
  - "확인되지 않은 개발자" 경고가 뜨면 파일을 **우클릭 → 열기 → 열기**를 누르세요. 처음 한 번만 하면 됩니다.
  - 그래도 안 되면 터미널에서 실행하세요: `cd 압축푼폴더 && bash "이코테 Judge 실행 (Mac).command"`
- **Windows**: `이코테 Judge 실행 (Windows).bat`을 더블클릭하세요.

실행하면 브라우저에서 http://localhost:8000 이 열립니다. 서버 창(터미널)은 풀이를 마칠 때까지 켜 두세요.

## 사용법
- 왼쪽 목록에서 문제를 고르고, 오른쪽에 코드를 작성합니다. 작성한 코드는 자동으로 저장됩니다.
- **코드 실행**(Ctrl+Enter): 책의 예제만 실행합니다.
- **제출 후 채점하기**(Ctrl+Shift+Enter): 숨겨진 테스트까지 채점합니다. 각 문제에는 최대 크기 테스트가 들어 있어서, 시간복잡도가 나쁜 풀이는 **시간 초과**를 받습니다.
- **채점 환경**은 실제 시험에 맞춰 두었습니다.
  - 표준입출력 문제(백준·삼성형): **PyPy3**
  - `solution` 함수 문제(카카오·프로그래머스형): **Python 3**
- **모의고사**: 오른쪽 위 버튼을 누르면 범위, 문제 수, 시간을 정해 무작위 문제를 풀 수 있습니다.

## 맞힌 풀이를 GitHub에 자동으로 올리기 (선택)
기본 설정에서는 맞힌 풀이가 `judge/data/solutions/`에 장별로 저장되고, 진행 현황 README도 함께 만들어집니다.

내 GitHub 저장소에 자동으로 커밋하고 push하려면 아래 순서대로 하세요.
1. GitHub에 저장소를 만들고, 이 폴더 옆에 clone하세요(예: `git clone https://github.com/내아이디/Algorithm`). 한 번은 직접 push해서 로그인해 두세요.
2. `judge/config.json`을 열어 `"repo"`에 저장소 경로를 넣으세요. judge 폴더 기준의 상대 경로나 절대 경로 모두 됩니다.
   ```json
   { "repo": "../Algorithm", "subdir": "이것이코딩테스트다", "push": true, "port": 8000 }
   ```
3. 서버를 다시 실행하세요.

이제 문제를 맞힐 때마다 `이것이코딩테스트다/<장>/<문제>/`에 풀이가 커밋되고, README의 장별 진행바도 갱신됩니다. 커밋만 하고 push는 하고 싶지 않으면 `"push": false`로 두세요.
