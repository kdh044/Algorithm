# 이코테 Judge

「이것이 취업을 위한 코딩 테스트다 with 파이썬」 문제를 로컬에서 채점하는 사이트입니다.

## 실행
Python 3.10 이상에서 이 폴더를 연 뒤 `python judge.py`를 실행하세요. 그러면 http://localhost:8000 이 열립니다. 별도 패키지 설치는 필요하지 않습니다.

전체 71문제는 프로그래머스 방식의 `solution(...)` 함수로 풉니다. 기본 코드에는 import나 표준입력 코드가 없으며, 인자로 받은 값을 처리해 정답을 반환합니다. 기존 표준입출력 문제 62개와 테스트 1,253개를 함수형으로 변환했습니다. 원본 조건을 위반한 격자 테스트 3개는 제외했습니다.

## 기능
- 예제 실행(Ctrl+Enter): 책의 예제만 실행하고 내 출력과 기대 출력을 비교해 보여줍니다.
- 제출(Ctrl+Shift+Enter): 숨겨진 케이스를 포함한 모든 테스트로 채점합니다. 백준처럼 처음 틀린 케이스에서 멈춥니다.
  - 각 문제에는 최대 크기 케이스가 들어 있어서 시간복잡도가 나쁜 풀이는 **시간 초과**를 받습니다.
  - 모두 맞으면 `Algorithm/이것이코딩테스트다/<장>/<문제>/`에 코드와 README를 저장하고, 자동으로 commit과 push를 합니다.
- 함수형 문제는 예제 실행으로 인자와 반환값을 확인합니다.
- 모의고사: 범위, 문제 수, 제한 시간을 정하면 무작위로 문제를 내 줍니다.
- 작성 중인 코드는 `data/drafts/`에 자동 저장되고, 제출 기록은 `data/status.json`에 남습니다.

## 문제 추가/수정
`tools/AUTHORING.md`를 참고하세요. 변환된 62문제의 `ref.py`와 `gen.py`는 원래의 표준입출력 참고 자료입니다. 이 문제들의 테스트 재생성은 비활성화되어 있으며, 채점에는 `tests/*.json`을 사용합니다.

개인 제출 기록, 작성 중인 코드, 로컬 백업, 인터프리터 실행 파일은 포함하지 않습니다. Git 연동 경로는 필요하면 로컬 `config.json`에서 설정하세요. 저장소 안의 `judge` 폴더에서 실행할 경우 `repo`를 `".."`로 지정하면 됩니다.
