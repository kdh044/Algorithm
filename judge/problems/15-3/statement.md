도현이의 집 N개가 수직선 위에 있습니다. 각각의 집의 좌표는 x<sub>1</sub>, x<sub>2</sub>, ..., x<sub>N</sub>이고, 집 여러 개가 같은 좌표를 가지는 일은 없습니다.

도현이는 언제 어디서나 와이파이를 즐기기 위해서 집에 공유기 C개를 설치하려고 합니다. 최대한 많은 곳에서 와이파이를 사용하려고 하기 때문에, 한 집에는 공유기를 하나만 설치할 수 있고, 가장 인접한 두 공유기 사이의 거리를 가능한 크게 하여 설치하려고 합니다.

C개의 공유기를 N개의 집에 적당히 설치해서, 가장 인접한 두 공유기 사이의 거리를 최대로 하는 프로그램을 작성하세요.

## 함수 설명

`def solution(n, c, houses):`

아래 매개변수는 원문에 등장하는 값과 같은 의미입니다. 배열 길이와 함께 주어지는 개수는 항상 일치합니다. 표준입력을 읽거나 정답을 출력할 필요 없이 결과를 반환하세요.

- `n` (정수): 원문의 N에 해당하는 값
- `c` (정수): 원문의 C에 해당하는 값
- `houses` (정수 배열): 집 위치의 정수 배열

## 반환값

-  가장 인접한 두 공유기 사이의 최대 거리를 반환합니다.

반환 형식: **정수**. 여러 값을 출력하던 문제는 예시와 같이 배열로 반환합니다. 문자열의 대소문자는 예시와 동일하게 맞추세요.

## 제한 사항

N, M 등의 기호는 같은 이름의 소문자 매개변수 또는 해당 배열의 길이를 뜻합니다. 각 배열의 원소 순서와 번호 체계는 문제 설명을 따릅니다.
-  집의 개수 N(2 ≤ N ≤ 200,000)과 공유기의 개수 C(2 ≤ C ≤ N)가 하나 이상의 빈칸을 사이에 두고 주어집니다.
-  집의 좌표를 나타내는 x<sub>i</sub>(1 ≤ x<sub>i</sub> ≤ 1,000,000,000)가 한 줄에 하나씩 주어집니다.
