n(1 ≤ n ≤ 100)개의 도시가 있고, 한 도시에서 출발하여 다른 도시에 도착하는 m(1 ≤ m ≤ 100,000)개의 버스가 있습니다. 각 버스는 한 번 사용할 때 필요한 비용이 있습니다. 모든 도시의 쌍 (A, B)에 대해서 도시 A에서 B로 가는 데 필요한 비용의 최솟값을 구하는 프로그램을 작성하세요.

## 함수 설명

`def solution(n, m, buses):`

아래 매개변수는 원문에 등장하는 값과 같은 의미입니다. 배열 길이와 함께 주어지는 개수는 항상 일치합니다. 표준입력을 읽거나 정답을 출력할 필요 없이 결과를 반환하세요.

- `n` (정수): 원문의 N에 해당하는 값
- `m` (정수): 원문의 M에 해당하는 값
- `buses` (정수 배열 배열): [출발 도시, 도착 도시, 비용] 배열

## 반환값

- 을 출력해야 합니다. i번째 줄에 출력하는 j번째 숫자는 도시 i에서 j로 가는 데 필요한 최소 비용입니다. 만약, i에서 j로 갈 수 없는 경우에는 그 자리에 0을 반환합니다.

반환 형식: **정수 배열 배열**. 여러 값을 출력하던 문제는 예시와 같이 배열로 반환합니다. 문자열의 대소문자는 예시와 동일하게 맞추세요.
도시별 최소 비용은 n × n 정수 배열로 반환합니다. 도달할 수 없는 곳은 0입니다.

## 제한 사항

N, M 등의 기호는 같은 이름의 소문자 매개변수 또는 해당 배열의 길이를 뜻합니다. 각 배열의 원소 순서와 번호 체계는 문제 설명을 따릅니다.
-  도시의 개수 n(1 ≤ n ≤ 100)이 주어집니다.
-  버스의 개수 m(1 ≤ m ≤ 100,000)이 주어집니다.
-  다음과 같은 버스의 정보가 주어집니다. 먼저 처음에는 그 버스의 출발 도시의 번호가 주어집니다. 버스의 정보는 버스의 시작 도시 a, 도착 도시 b, 한 번 타는 데 필요한 비용 c로 이루어져 있습니다. 시작 도시와 도착 도시가 같은 경우는 없습니다. 비용은 100,000보다 작거나 같은 자연수입니다.
- 시작 도시와 도착 도시를 연결하는 노선은 하나가 아닐 수 있습니다.
