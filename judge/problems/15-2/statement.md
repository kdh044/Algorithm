고정점(Fixed Point)이란, 수열의 원소 중에서 그 값이 인덱스와 동일한 원소를 의미합니다. 예를 들어 수열 a = {-15, -4, 2, 8, 13}이 있을 때 a[2] = 2이므로, 고정점은 2가 됩니다.

하나의 수열이 n개의 서로 다른 원소를 포함하고 있으며, 모든 원소가 오름차순으로 정렬되어 있습니다. 이때 이 수열에서 고정점이 있다면, 고정점을 반환하는 프로그램을 작성하세요. 고정점은 최대 1개만 존재합니다. 만약 고정점이 없다면 -1을 반환합니다.

단, 이 문제는 시간 복잡도 O(logN)으로 알고리즘을 설계하지 않으면 '시간 초과' 판정을 받습니다.

(인덱스는 0부터 시작합니다.)

## 함수 설명

`def solution(n, numbers):`

아래 인자를 받는 solution 함수를 완성하세요. 문제 설명과 제한 사항은 함수 인자와 같은 이름을 사용합니다. 배열과 함께 주어지는 개수는 배열 길이와 일치합니다.

- `n` (정수): 문제에서 설명한 n 값
- `numbers` (정수 배열): 문제에서 주어진 수들의 배열

## 반환값

- 고정점을 반환합니다. 고정점이 없다면 -1을 반환합니다.

반환 형식: **정수**.

## 제한 사항

- 1 ≤ n ≤ 1,000,000
- len(numbers) = n
- -1,000,000,000 ≤ numbers[i] ≤ 1,000,000,000
- numbers는 서로 다른 원소가 오름차순으로 정렬된 배열이며 인덱스는 0부터 시작합니다.
