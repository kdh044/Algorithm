n개의 원소를 포함하고 있는 수열이 오름차순으로 정렬되어 있습니다. 이때 이 수열에서 x가 등장하는 횟수를 계산하세요. 예를 들어 수열 {1, 1, 2, 2, 2, 2, 3}이 있을 때 x = 2라면, 현재 수열에서 값이 2인 원소가 4개이므로 4를 반환합니다.

단, 이 문제는 시간 복잡도 O(logN)으로 알고리즘을 설계하지 않으면 '시간 초과' 판정을 받습니다.

## 함수 설명

`def solution(n, x, numbers):`

아래 인자를 받는 solution 함수를 완성하세요. 문제 설명과 제한 사항은 함수 인자와 같은 이름을 사용합니다. 배열과 함께 주어지는 개수는 배열 길이와 일치합니다.

- `n` (정수): 문제에서 설명한 n 값
- `x` (정수): 문제에서 설명한 x 값
- `numbers` (정수 배열): 문제에서 주어진 수들의 배열

## 반환값

- 수열의 원소 중에서 값이 x인 원소의 개수를 반환합니다. 단, 값이 x인 원소가 하나도 없다면 -1을 반환합니다.

반환 형식: **정수**.

## 제한 사항

- 1 ≤ n ≤ 1,000,000
- len(numbers) = n
- -1,000,000,000 ≤ x, numbers[i] ≤ 1,000,000,000
- numbers는 오름차순으로 정렬되어 있습니다.
