동빈이네 전자 매장에는 부품이 N개 있다. 각 부품은 정수 형태의 고유한 번호가 있다. 어느 날 손님이 M개 종류의 부품을 대량으로 구매하겠다며 당일 날 견적서를 요청했다. 동빈이는 때를 놓치지 않고 손님이 문의한 부품 M개 종류를 모두 확인해서 견적서를 작성해야 한다. 이때 가게 안에 부품이 모두 있는지 확인하는 프로그램을 작성해보자.

예를 들어 가게의 부품이 총 5개일 때 부품 번호가 다음과 같다고 하자.

```
N = 5
[8, 3, 7, 9, 2]
```

손님은 총 3개의 부품이 있는지 확인 요청했는데 부품 번호는 다음과 같다.

```
M = 3
[5, 7, 9]
```

이때 손님이 요청한 부품 번호의 순서대로 부품을 확인해 부품이 있으면 yes를, 없으면 no를 반환한다. 구분은 공백으로 한다.

## 함수 설명

`def solution(n, parts, m, requests):`

아래 매개변수는 원문에 등장하는 값과 같은 의미입니다. 배열 길이와 함께 주어지는 개수는 항상 일치합니다. 표준입력을 읽거나 정답을 출력할 필요 없이 결과를 반환하세요.

- `n` (정수): 원문의 N에 해당하는 값
- `parts` (정수 배열): 보유한 부품 번호 배열
- `m` (정수): 원문의 M에 해당하는 값
- `requests` (정수 배열): 요청한 부품 번호 배열

## 반환값

-   각 부품이 존재하면 yes를, 없으면 no를 반환한다.

반환 형식: **문자열 배열**. 여러 값을 출력하던 문제는 예시와 같이 배열로 반환합니다. 문자열의 대소문자는 예시와 동일하게 맞추세요.

## 제한 사항

N, M 등의 기호는 같은 이름의 소문자 매개변수 또는 해당 배열의 길이를 뜻합니다. 각 배열의 원소 순서와 번호 체계는 문제 설명을 따릅니다.
-  정수 N이 주어진다. (1 ≤ N ≤ 1,000,000)
-  공백으로 구분하여 N개의 정수가 주어진다. 이때 정수는 1보다 크고 1,000,000 이하이다.
-  정수 M이 주어진다. (1 ≤ M ≤ 100,000)
-  공백으로 구분하여 M개의 정수가 주어진다. 이때 정수는 1보다 크고 1,000,000 이하이다.
